# 开发任务

记录目标行为、现有实现、Profile 影响、授权范围、必要契约/迁移/权限、验证命令与未验证边界。先保护工作区，只读相关规范和代码；完成后报告文件、风险及结果，不用历史结果冒充本轮验收。

疑似框架通用 Bug 或源码同步任务，按[框架升级与反馈](../product/framework-upgrade.md)补充问题归属、框架来源/当前模板提交、最小复现、本地临时补丁、上游反馈草稿或实际 Issue/PR，以及模板发布与下游同步验证状态。记录留在 build/ 或仓库外，公开发送沿用用户授权。
