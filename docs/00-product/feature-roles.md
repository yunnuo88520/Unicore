# M2d 业务角色与权限管理

目标：让平台管理员为业务创建职责清楚的角色，并在用户管理中分配。只适用于 web-platform；其他形态无菜单和平台 API。

管理员可创建、查看、改名、修改权限、删除未关联用户的业务角色。列表显示内置/业务类型、关联用户数量和权限数；编辑器按资源分组，显示权限名称、标识与用途。内置普通用户/超级管理员固定；角色、用户身份和实例配置写权限显示但不可委派。支持只读角色查看、空白编辑、错误提示、加载与保存/删除成功反馈，删除需页面内确认。

用户创建/角色选择使用真实角色目录。可创建用户的业务账号只能授予自己权限范围内的角色；服务端独立校验。用户状态和角色更换仍由超管执行，不能禁用或降权最后一个启用超管。当前账户按既有 API 关联一个角色；后续如需多角色编辑需扩展契约和交互。

保存角色后撤销相关用户的旧会话和待用账号验证码；他们重新登录后获得新权限。有关联用户的角色不能直接删除。前端菜单仅用于交互可见性，服务端逐 API 鉴权并在事务内复核写入权限。

验收：升级旧数据库后保留用户/设置/既有权限，超管得到新增角色权限；匿名 401、无权 403、缺失 CSRF 拒绝；保护内置角色、最后超管与不可委派权限；验证跨权限委派拒绝、会话/码撤销以及分配与删除并发一致性。PC/375px、浅深/system 与键盘操作；回归其他已有页面和四形态构建。
