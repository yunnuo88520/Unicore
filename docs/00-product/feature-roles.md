# 平台用户与固定角色

仅 web-platform 装配身份。管理员（super_admin）和普通用户（user）分别使用独立账号、会话、验证码、恢复和企业绑定表；相同用户名/邮箱可以并存，凭据不能跨域使用。角色和权限由代码固定，不提供自定义角色、委派或升降身份。角色页只读，显示两类数量与权限矩阵。

| 能力 | 管理员 | 普通用户 |
| --- | --- | --- |
| 工作台概览、Core、本人个人中心/改密/企业绑定 | 允许 | 允许 |
| 当前客户端外观 | 允许 | 允许 |
| 独立用户/管理员列表、弹窗新增、启停 | 允许 | 拒绝 |
| 角色权限目录 | 允许 | 拒绝 |
| 基础设置、邮件设置、系统日志、系统更新/授权占位 | 允许 | 拒绝 |

管理员从可配置后台入口（默认 /admin）登录，普通用户从 /login 或 / 登录。公开登录壳不提供管理数据；两域使用不同 Cookie 与固定 API 路径；管理员路径统一 /api/v1/admin/*，不能自动回退。安装后的初始账号写入管理员表，完成页跳转后台。注册和企业 JIT 仅建普通用户，管理员 JIT 禁止；绑定按 issuer/sub 识别，不按邮箱合并。

工作台概览一级默认。用户管理包含用户列表、管理员列表、角色权限。“系统管理”为静态分区标签，下设“系统设置”和“个人中心”独立折叠菜单；系统设置承载基础设置、邮件、模板、公告、对象存储、日志和更新，个人中心包含个人资料、安全设置和登录会话。普通用户只显示个人中心与当前客户端外观。选中背景仅在实际二级页面，父菜单仅用文字色提示；直达页面自动展开所属菜单。固定侧栏导航独立滚动，底部作者区可见；头像菜单保留快捷改密、个人中心、退出。双入口权限与 API 不因分区调整而改变。

全局设置影响所有用户，但仅管理员可读写；公共 bootstrap/Logo/favicon/版权/最小登录策略不公开敏感数据。普通用户设置仅本地外观，不请求管理 API。服务端逐 API 校验有效管理员/权限，写入校验 CSRF/Origin；账号写事务重查管理员域操作者。历史 grants 不授权普通用户，最后启用管理员及最后有本地密码管理员不能禁用。

0007 将旧自定义角色归普通用户，0008 迁移管理员账号和企业绑定到独立表，保留 ID/密码；两次升级均撤销旧凭据、取消待发邮件。升级前成套备份，恢复匹配 DB/目录/密钥和程序，见 [部署手册](../03-runbooks/deployment.md)。实现决策见 [ADR-0014](../adr/ADR-0014-separate-identities-management.md)，旧角色同表方案不作为当前规则。

当前双入口、单机边界和升级兼容说明见 [ADR-0016](../adr/ADR-0016-separate-client-admin-surfaces.md)。

个人中心完整需求与安全规则见 [运行说明](../03-runbooks/personal-center.md) 和 [ADR-0030](../adr/ADR-0030-personal-center-security.md)。包含昵称、两步邮箱验证、TOTP 与一次性恢复码、全部登录入口的二次验证、本人设备查看/单个或其他设备下线；不增加角色委派或普通用户管理权限。
