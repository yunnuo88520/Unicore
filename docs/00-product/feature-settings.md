# 系统设置与可裁剪扩展

系统管理分为基础设置、账户安全、邮件设置、邮件模板、系统日志、系统更新与可选授权。基础设置使用单层 Tabs（基础信息、品牌图片、外观、安全与控制（后台入口）、注册设置、维护模式、企业登录）；保留品牌三卡片、外观预览卡片及切换草稿。平台外观仅当前客户端 localStorage；普通用户只可访问这一项。单机/桌面保留本地默认外观。

邮件设置将 SMTP 配置、账号邮件策略和真实发送测试合并到一页，无子标签；测试收件地址在弹窗填写。投递记录在系统日志的邮件投递页，与操作日志并列；邮件模板为独立页面，使用单层场景 Tabs 配置主题/受限 HTML 正文，支持变量、预览、指定收件人测试与恢复默认，保留品牌框架。具体边界见 [管理工具手册](../03-runbooks/admin-tools.md) 与 [ADR-0020](../adr/ADR-0020-audit-mail-templates.md)。全局设置/品牌/SMTP 仅管理员读写，投递和审计需要 logs:read；写请求校验 CSRF/Origin，敏感值不回传。设置源仍为 SettingDefinition。

站点名/版权/备案信息用于工作台和公开登录/注册/找回页面；备案号留空隐藏，查询链接留空显示纯文本，非空只接受无凭据的 HTTPS。读取旧数据时 UI 再次限制可点击链接。新增设置由默认值补齐，复用 system_settings，无 schema 迁移。

favicon 兼容 PNG/JPEG 与 ICO，Logo 仍只接受 PNG/JPEG。ICO 支持 PNG frame 和未压缩 BITMAPINFOHEADER DIB（1/4/8/24/32 位），最多 64 帧，选择最大可用尺寸 16–256 像素，校验偏移/体积/调色板/透明掩码后转成 PNG；不原样提供 ICO 内容。全部原图不超过 256 KiB。其余持久化/清理边界见 [实例品牌](feature-branding.md)。

mail.from_name 留空时使用邮件内的站点名称；非空作为测试/账号/系统通知的 MIME 显示名，信封发件邮箱仍由 mail.from 决定。别名不影响连接与凭据，修改别名不撤销已有 SMTP 连通性测试；主机/端口/TLS/邮箱/账号/密钥变更沿用指纹失效规则。密钥加密且 API 不回传。注册/六位码登录/重置使用十分钟六位码，不以验证码充当系统通知。

系统设置提供独立的通知渠道、通知模板、系统通知二级菜单。企业微信与 Webhook 二选一，普通用户邮件、管理员邮件和管理员渠道按事件独立控制；系统通知默认关闭，不影响验证码与密码找回。凭据加密、模板纯文本、业务事件同事务入队并异步重试。覆盖框架实际支持的登录、IP 封禁、密码、2FA、账号状态、注册、创建账号、会话撤销及邮箱变更，不增加订单/余额/授权空开关。原直接邮件 Notify 保留兼容。参数、默认值、协议、重试及后续业务接入见 [事件通知](../03-runbooks/notifications.md)。

## 授权与更新的编译边界

FEATURE_LICENSE 默认 false，保留独立授权服务待对接卡片；FEATURE_UPDATER 默认 true，提供真实签名 OTA 与内置历史。均只接受 true/false，Make 映射为 license/updater Go tags，Vite 编译常量裁剪相同功能。禁用更新时不装配渠道/安装器，CLI 始终不装配；capability 由实际组合根服务决定。

平台版本页面与更新 API 仅管理员，本地系统更新由 loopback/原生桥接开放。Docker 只检查、不覆盖自己。签名、备份确认、兼容边界和恢复见 [更新需求](feature-updates.md)、[ADR-0018](../adr/ADR-0018-signed-updates.md)、[运行手册](../03-runbooks/updates.md)。没有新增设置表或数据库迁移；渠道与信任根由受控构建/部署配置管理，不能让远端 feed 修改公钥。

在线平台新增独立“对象存储”设置页，用本地/MinIO/S3/OSS/COS 选择器直接展示配置表单，进入默认选中当前全局方式；仅管理员可见，默认本地，测试后显式切换，文件策略登记 storage.*。详见 [文件存储](feature-storage.md) 与 [运行手册](../03-runbooks/storage.md)。

当前单机/桌面只提供本地外观，拒绝站点/品牌/邮件等设置，详见 [ADR-0016](../adr/ADR-0016-separate-client-admin-surfaces.md)。布尔设置用 Switch；开放注册与邮箱验证为独立开关，新实例默认均关闭；关闭验证时无需 SMTP，注册立即激活。注册图形验证码默认开启，保留限流；开启邮箱验证前必须通过 SMTP 测试。

本地外观新增共享右侧抽屉与中英文入口；既有外观页的更多设置复用该抽屉。即时偏好只写当前客户端，不进入 SettingDefinition 或实例 PATCH；具体选项和兼容见 [客户端偏好](../03-runbooks/client-preferences.md)。

## 站点地址、页脚与维护

基础信息中的 site.base_url 仅决定新邮件链接（包括模板预览和旧版账号链接），留空沿用安装地址；不改变监听地址、Cookie 安全策略或 OIDC 固定回调。新安装默认保存安装地址和管理员邮箱，旧实例留空回退。site.admin_email 不公开到 bootstrap；内部 Notify 的 To 留空时发送到此邮箱，具体告警事件由业务接入，不自动订阅所有设置变更。

site.police_number 在公开账号页和工作台页脚显示；site.footer_html 支持受限段落、列表、强调和 HTTP/HTTPS 链接，服务端拒绝脚本/事件属性/样式/嵌入，浏览器再次净化。用户内容原样展示，不自动翻译。所有字段复用 system_settings，无 schema 迁移。

维护模式默认关闭，提示可填写多行文字。开启后，用户页面展示维护提示，用户业务/认证/文件 API 返回 503 MAINTENANCE_MODE；bootstrap 与健康检查保留。用户页面每 30 秒复核维护状态，管理员入口和独立管理 API 保持原鉴权以便恢复。已经签发的云下载仍遵循有效期，已发起的请求不回滚；本地签名下载在维护期间暂停。关闭后用户可重新检查或等待自动复核恢复。仅 web-platform 提供这些设置。

## 双重验证策略

security.force_admin_2fa 和 security.force_user_2fa 默认 false，security.allow_disable_2fa 默认 true，由管理员在账户安全中配置。前两个开关分别强制对应身份中尚未绑定验证器的账号先完成个人中心设置，后者控制本人能否关闭；强制开启时禁止关闭。旧 security.force_2fa 保留接口兼容并映射两域。两域登录后的二次验证、恢复码和设备撤销见 [个人中心](../03-runbooks/personal-center.md)。设置只作用在线平台，不暴露 SMTP 或验证器密钥。

## 注册限制与兼容

基础信息按站点名称、站点描述、站点地址、管理员邮箱、页脚版权、备案号、备案查询链接、公安备案号、自定义页脚 HTML 排列。注册设置同一标签提供开放注册、邮箱验证、图形验证码、邮箱后缀模式/列表与昵称、用户名、密码、IP 黑名单，所有限制由后端执行。后缀精确匹配域名，不自动允许子域，可选不限制/白名单/黑名单，同时限制注册验证邮件的发送；不妨碍已有账号找回密码。昵称/用户名为不区分大小写的包含匹配，命中拒绝注册或资料修改；密码为不区分大小写的完整匹配，作用于注册、本人改密与重置。IP 支持单 IP、CIDR、连续末尾 IPv4 通配符（如 203.0.113.*），按真实 socket IP 判断，不信任可伪造的转发头；反向代理后的客户端 IP 过滤应由可信入口另行配置，应用见到的地址可能是代理地址。

列表每行一条、最多 200 条/16000 字符；非法格式保存失败。审计不记录限制词列表值或用户提交的密码。复用现有设置表，无 schema 迁移。缺少新键且已经开放注册的旧实例继续要求邮箱验证；保存开放注册开关时显式固化兼容值，须管理员明确关闭验证，避免升级无意减弱策略。已有 pending 账号不会被批量激活；关闭验证后可联系管理员处理账号状态。

账户安全是系统设置的独立二级菜单，复用 settings:read/write API 权限。提供登录失败阈值、IP 临时封禁时长、两域空闲超时、管理员最长登录时间、两域强制 2FA、允许关闭及登录图形验证码/会话时长。强制开关相互独立，旧 security.force_2fa 在读取时映射两域，显式保存后固化；兼容旧 API 修改并同步两域。会话时间使用现有 session_details.created_at/last_seen_at，无新增 schema；旧会话缺少详情时仍按原有效期处理。状态轮询不算用户活动，实际业务请求续空闲时间，不能超过绝对时限。IP 连续失败计数按进程/身份域隔离，有界内存，重启清空；永久限制用持久 IP 黑名单。全部时间和限制均由服务端执行。
