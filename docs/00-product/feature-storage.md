# 文件与对象存储

| 能力 | web-platform | web-standalone / desktop | cli |
| --- | --- | --- | --- |
| 文件管理、直传、私有签名访问 | 新增 | 不装配 | 不装配 |
| 管理员存储配置、测试与切换 | 新增，默认本地 | 不装配 | 不装配 |
| 统一品牌存储 port | 使用元数据管理 | 本地 adapter | 不装配 |

设置提供本地、MinIO、Amazon S3、阿里云 OSS、腾讯云 COS 单层标签；位置用弹窗新增，敏感值加密且编辑留空保持。修改 endpoint/bucket/prefix 需新增位置，防止历史文件错位。非默认且无文件和待清理任务的位置可删除。管理员可测试连接、配置浏览器跨域、选择默认；普通用户不可读取配置。

文件管理支持弹窗上传、本人分页列表、授权下载、删除；管理员可查看和迁移文件。通过 file_id 关联业务，元数据含原名、提供商、位置、对象键、MIME、长度、创建人/身份域、时间与状态。凭证不入库明文，不作为永久外链。

验收覆盖：本地与真实 MinIO、权限/跨用户/身份域、凭证过期/重放、失败和重启恢复、历史位置不变、品牌兼容、三数据库迁移、PC/375px/深浅主题与 Wails 品牌流程。OSS/COS/S3 只有拥有对应测试环境才能声明云端实测。设计见 ADR-0015。
