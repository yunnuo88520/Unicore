# 文件与对象存储

| 能力 | web-platform | web-standalone / desktop | cli |
| --- | --- | --- | --- |
| 业务文件上传、续传、授权下载与清理 | 已实现，支持本地及云位置 | 已实现，固定本地位置 | 不装配 |
| 管理员存储配置、测试与切换 | 已实现，默认本地 | 不装配 | 不装配 |
| 全局文件目录与批量迁移 | 已实现，仅超级管理员 | 不装配 | 不装配 |
| 统一品牌存储 port | 使用元数据管理 | 仅构建品牌，无运行时存储 | 不装配 |

设置提供本地、MinIO、Amazon S3、阿里云 OSS、腾讯云 COS 横向切换，进入默认选择当前全局方式；每种方式展示一份配置，不提供位置名称、新增位置或多配置选择器。顶部统一显示全局默认，仅非当前配置提供启用操作，需先保存并测试连接。敏感值加密且编辑留空保持，已保存的 endpoint/bucket/region/prefix 只读以保护历史文件引用。全局同时仅一个生效位置，新文件随当前配置上传；旧位置只为历史文件保留，不自动删除或迁移。上传路径、扩展名、大小与生命周期归入独立“上传规则”；分片和清理设置折叠展示。普通用户不可读取配置。

文件服务与统一上传组件支持分片上传、真实字节进度、暂停/继续/放弃、刷新及服务重启续传、授权下载和生命周期。Platform 超级管理员具有独立文件治理页面，位于运行监控与 AI 管理之间，统一查看目录、上传者姓名/账号、分页搜索、下载、引用保护删除与本地/云端批量迁移；普通用户及 Standalone 无全局文件管理页面。全局默认存储启用后，统一上传自动使用该位置；历史文件仍按 location_id 访问。通过 file_id 关联业务，元数据含原名、提供商、位置、对象键、MIME、长度、创建人/身份域、时间与状态。凭证不入库明文，不作为永久外链。文件治理的权限、迁移与引用保护见 ADR-0051。

已有开发验证覆盖本地、MinIO 与 OSS；COS、AWS S3 及其他 S3 服务仍须在目标环境验证权限、CORS 和分片上传。文件治理另覆盖权限与身份域、引用保护、迁移完整性与签名访问兼容、PC/375px 和深浅主题；这些本地回归不等同于云厂商验收。支持范围以 [支持范围](../support.md) 为准，存储位置设计见 ADR-0015。

上传策略可视化且仅管理员可写，本地及全部云提供商统一生效。默认 100 MiB，配置上限 64 GiB；分片、并发、续传窗口与链接/保留期可调；多条自定义上传路径与允许扩展名统一配置、后端校验，旧会话保持快照。续传重新选择原文件并验证完整 SHA-256；云分片仍为浏览器直传。平台迁移 0012、清理与兼容边界见 [ADR-0022](../adr/ADR-0022-resumable-uploads.md)，厂商与性能限制见 [支持范围](../support.md)。

迁移只支持本地与云端双向转换，不支持云提供商或云位置之间直接互迁。文件管理可选择全部迁移成功后切换全局默认；失败保留当前默认，切换不会重定向历史引用。
