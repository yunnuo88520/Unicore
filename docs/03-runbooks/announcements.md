# 平台公告与内容管理

仅在线多用户 web-platform 提供公告。管理员在“系统管理 → 系统设置 → 平台公告”管理，普通用户通过全局顶部铃铛查看，工作台不再轮播。管理员入口、单机、Wails 和 CLI 不加载用户公告中心。展示开关默认开启；关闭后用户列表为空、未读数为零，详情和单条已读写入返回 404（全部已读不写入记录），下一次刷新移除用户内容。

## 编辑与发布

新增默认草稿、静默通知、全部用户。独立标题最多 200 个 Unicode 字符，Markdown/HTML 正文源码最多 10,000 个字符，内部备注最多 100 字。类型为通知、好消息、注意事项、重要提醒。预览使用后端同一安全渲染器；脚本、图片、内嵌页面、事件和样式不允许，链接仅允许安全 HTTP(S)。用户投影不含内部备注、接收人列表或管理员信息。

发布状态为草稿、已发布、已归档。未来发布时间为定时发布；可选结束时间必须严格晚于发布时间，留空为永久有效。服务端每次查询按 `发布时间 ≤ 当前时间 < 结束时间` 判断，无需定时任务；到期仅停止展示，不自动修改为归档。归档和草稿均不公开。

接收范围可选全部用户或最多 500 位指定普通用户；指定用户通过账号/邮箱搜索和分页勾选。后端验证用户真实存在，并在分页、详情、未读统计及已读写入前检查接收范围。框架不包含余额/订阅组规则，不引入特定产品计费模型。

管理列表支持标题/内容/备注搜索、状态筛选、分页和批量软删除。修改、删除保留乐观版本检查；任一批量条目冲突则全部回滚。管理写操作在事务内复核管理员权限并写审计。

## 用户通知与阅读记录

铃铛显示全量当前可见未读数，列表每页 10 条、未读优先，支持详情和全部标为已读。打开详情重新鉴权并记录首次已读；全部已读由后端在事务内处理所有当前可见公告，不局限于当前页。

静默公告只进入列表。弹窗公告在用户进入工作区约 3 秒后逐条展示，独立查询未读弹窗，不受列表翻页影响。用户点击“标为已读”并保存成功后关闭；请求失败保留弹窗与重试入口。正式弹窗不能用遮罩或 Escape 跳过，但没有阅读时长、倒计时或滚动完成验证。阅读时间仅表示首次打开或确认，不证明阅读完成。

已读记录按普通用户与公告唯一保存，重复请求不覆盖首次时间。修改内容、通知方式或接收范围不会重置已读；需要再次提醒请新建公告。会话变化通过 SessionBoundary 清理查询和本地状态，不持久化用户公告到 localStorage。

公告中心每 60 秒和窗口重新聚焦时刷新；已打开详情每 15 秒复核，已加载公告到结束时间会触发刷新。不是实时推送，撤回或关闭总开关到前端清除之间可能有刷新延迟，服务端下一次详情/已读请求立即按当前规则拒绝。

管理员“阅读情况”按账号/邮箱搜索并分页显示用户、当前接收资格和首次已读时间。资格反映当前配置，不是发布时接收人快照；尚未实现送达统计或公告邮件推送。公告正文为用户业务数据，不随界面语言自动翻译；控件和反馈支持中英文及明暗主题。

## 迁移与恢复

当前运行体系在平台 0014 后追加三方言 0015，增加标题、通知方式、结束时间、接收范围以及接收人/阅读表。旧公告保留原内容、状态与时间，默认标题为 Announcement、静默、全部用户、无结束时间；管理员可编辑标题。旧 SQL 和 checksum 不变。未启用的新 namespace Catalog 同步追加 platform@2，不切换运行时执行器。

升级前停服并备份完整数据库、数据目录及密钥。增量迁移在实例启动边界执行；MySQL DDL 隐式提交，若中断导致部分列已增加，不删账本、不覆盖 checksum、不盲目重试，恢复匹配备份到新目标后重新启动。回退必须同时恢复匹配数据库与二进制，不能仅换旧二进制。见 [备份手册](backup.md)。

## 开发与验证

入口为 domain/announcement、usecase/announcements、announcementsql、adapter/content/announcement、HTTP announcements、前端 announcement-center 与 pages/admin/announcements。接口以 OpenAPI 生成；用户已读接口仅对应域本人会话，写操作要求 CSRF，管理员阅读查询要求 announcements:read。announcements.enabled 仅允许专用端点修改。

Go 公告套件默认执行隔离 SQLite；UNICORE_ANNOUNCEMENT_MYSQL_DSN / UNICORE_ANNOUNCEMENT_POSTGRES_DSN 仅用于显式授权的独立空库，不能指向业务实例，也不能与其他包共用测试库。浏览器测试 tests/e2e/announcements.spec.ts 覆盖双域、移动宽度、英文深色、弹窗失败重试、分页、首次已读、定向隔离与本地无请求。实际支持与未测方言以当次验证结果为准。
