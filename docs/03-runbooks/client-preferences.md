# 语言与外观

Platform、Standalone Web 和桌面应用都可在顶栏切换语言、明暗模式和主题。设置保存在当前浏览器或桌面 WebView，不上传服务器，也不影响其他设备或账号。

## 切换语言

点击顶栏语言按钮，选择简体中文或 English。切换只改变系统界面，笔记、文件名、公告和邮件内容保留原文。正在填写的表单保持当前输入。

## 调整外观

打开主题设置抽屉，可调整配色、圆角、密度和布局，选项立即生效。点击重置会恢复默认外观，并保留当前语言。

相同浏览器、相同站点的多个标签会同步外观；其他浏览器和设备各自保存。退出登录不会清除设备偏好。浏览器禁用本地存储时，设置只在当前运行期间生效。

## 使用导航

宽屏可将侧栏收起为图标栏；管理目录的子页面可从弹出菜单访问。菜单搜索只筛选当前有权访问的条目，匹配子页面时会展开父目录，按 Escape 清空搜索。

手机上通过导航按钮打开完整菜单抽屉。语言菜单和侧栏弹出菜单支持键盘操作；Escape 关闭后焦点回到原按钮。

## 定制应用的默认外观

应用开发者可通过 [主题与品牌](../02-standards/design-system.md) 设置构建时默认值，通过 [前端基础](frontend-foundations.md) 接入双语界面。设备偏好与管理员配置的站点品牌分别保存。
