# 个人中心

> 当前账号模型以 [ADR-0037](../adr/ADR-0037-unified-user-identity.md) 为准：统一账号可持多个业务/管理角色，两种工作台共用会话、密码、个人中心和资源归属。管理员/用户安全策略按实际管理权限选择；角色 realm 仅作工作台分类。旧双账号开发库须另建空库。

仅在线平台提供，管理员与普通用户使用各自入口。侧栏导航不再保留“个人中心”目录：点击侧栏底部账号卡片（或顶栏头像）菜单中的“个人中心”，打开设置弹窗，在左侧分区选择个人资料、安全设置、登录会话或访问令牌。强制启用两步验证的账号登录后弹窗自动打开并停留在安全设置，完成设置前不可关闭。“系统设置”保留管理员全局配置；当前客户端外观仍独立保存。

## 个人资料和邮箱

昵称可以修改，用户名不可修改。个人资料支持上传头像，通过现有文件服务上传后保存 `avatar_file_id`，页面使用服务端返回的短期访问 URL；不接受外部头像 URL 或磁盘路径。头像引用由当前身份域本人会话校验文件归属，管理员与普通用户保持独立；文件不可访问时显示默认头像。头像文件受统一存储策略、生命周期与备份规则约束，不能将临时 URL 当持久标识。角色、状态与双重验证状态为只读。更换邮箱先向当前邮箱发送六位码、验证后再向新邮箱发送六位码；验证码十分钟内有效、60 秒后可重发，最多五次错误。新邮箱必须不同且未被当前身份域的账号占用；同一邮箱可分别用于管理员和普通账号，不会合并身份。

邮箱流程需管理员先在邮件设置中配置并测试 SMTP；未就绪会明确报错。窗口取消不修改邮箱；验证码过期后重新发起。完成换绑后其他设备退出，待用验证码作废，当前设备保留。两步必须在同一设备/会话完成，不能把原邮箱验证交给另一设备复用。

## 安全设置

修改密码须输入当前密码、新密码和确认密码；新密码至少 12 字符，成功后全部设备需重新登录。原头像菜单的快捷改密入口保留。

设置身份验证器时输入当前本地密码，用支持 TOTP 的验证器扫描二维码或手动输入密钥，再输入六位码完成。Google Authenticator、Microsoft Authenticator 等标准 TOTP 应用均可扫描。绑定密钥保持稳定、10 分钟有效，可手动刷新或取消；每 30 秒变化的是验证器六位码，手动刷新后旧密钥失效，需要重新扫描。未设置本地密码的企业账号点击“验证企业身份并继续”，重新登录已绑定的企业账号后返回二维码设置，无需 SMTP 或本地密码。必须使用原绑定身份；另一个企业账号不能代为设置。企业验证流程 5 分钟有效，完成后生成仅当前会话可读取的 10 分钟设置密钥；取消会清除密钥，刷新需要再次企业验证。已有本地密码的账号仍需验证密码。企业登录关闭、企业身份服务不可用或不支持新鲜 auth_time 时不能完成该路径，请修复企业配置后重试。

开启后立即保存十个恢复码，可复制或下载。恢复码只展示一次，每个只能用一次；未保存就离开页面无法再次读取。正常登录先完成密码、邮箱或企业验证，再填验证器码；也可选择恢复码。二次验证限五分钟，八次错误后需重新登录。同一个验证器码不能在多个设备复用，需等待下一周期。恢复码用于登录，不能用于关闭双重验证。

关闭需输入验证器新代码；开启/关闭均下线其他设备。管理员可在系统设置 → 账户安全中分别强制管理员或普通用户启用两步验证，也可禁止本人关闭；默认不强制，允许本人关闭。强制策略开启后，对应身份中尚未完成设置的账号先完成安全设置才能使用工作台。已有企业账号绑定流程保留在安全设置；相同邮箱不会自动绑定。

## 登录设备

显示有效会话的设备描述、IP、登录与最近活动时间，标记当前会话。设备描述来自 User-Agent，仅供辨认；IP 是服务端实际连接地址，代理后可能为代理地址。旧版本会话缺少的字段显示未知。

可以确认下线某台设备或所有其他设备。下线当前设备会返回登录页；其他设备下一次请求立即失效。页面每 30 秒刷新，也可手动刷新。发现陌生会话应下线并修改密码。

## 访问令牌

“个人中心 → 访问令牌”分区独立管理本人脚本凭证。填写名称、可选备注，从自己的角色中选择一个，期限固定为 1、7、30、90 天或永久。令牌只继承所选角色的当前权限和数据范围，不合并账号其他角色；秘密只在创建时显示一次。

操作支持续期和作废。有限且有效的令牌从原到期时间延长，已过期或永久令牌选择有限期限则从现在计算；选择永久取消时间期限。续期保留秘密，作废立即生效且不可恢复。修改密码、账号/角色状态或下线其他设备引起的安全失效也不能通过续期复活。

超级管理员可在“超级管理员 → 访问令牌管理”搜索和管理全部用户的令牌，也可选择用户及其已有角色代为签发。普通管理员没有该全局入口。接口、权限与脚本示例见 [客户端与 API 认证](../product/api-authentication.md)。

## 升级、备份与恢复

当前个人中心结构在 Catalog 的 `platform@1` 基线中，头像引用由 `platform@1` 的 `unicore_account_avatars` 保存；单机/桌面不装配 platform。旧轨 0014 不再是当前迁移入口。Tar 停服替换程序后在实例启动边界迁移；Docker 由外部替换镜像并保留私有数据卷，不在容器内覆盖程序。迁移前按 [备份手册](backup.md) 成套备份数据库、私有目录/密钥及原版本；不要把真实验证码、恢复码或设置二维码保存到公开日志。

SQLite/PostgreSQL DDL 可事务回滚，MySQL 可能留下部分新表，重启可按幂等 CREATE 重试；结构冲突时停服恢复，禁止删账本/改 checksum。回退需恢复对应旧快照与旧程序，不能只降级二进制。实例密钥丢失会导致 TOTP 和待发邮件无法解密；恢复旧数据库还可能恢复旧会话或已用恢复码，须保护快照并防止新旧实例同时运行。安全设计见 [ADR-0031](../adr/ADR-0031-personal-center-security.md)。

全局安全策略位于系统设置的“账户安全”，与本人的“安全设置”分开。管理员/普通用户列表有只读双因素状态列，不暴露验证器密钥和恢复码。有管理权限与普通成员的强制 2FA 策略可分别开启；未绑定账号只允许完成本人安全设置，不能使用业务 API，也不能自行关闭强制策略。空闲超时按主动请求续期，后台状态轮询不续期；管理员最长登录时间从首次登录起计算，重启保留现有会话时间戳。连续登录失败会临时封禁统一登录服务的来源 IP，不冻结账号；计数仅在内存，进程重启清空，永久限制使用注册设置的 IP 黑名单。
