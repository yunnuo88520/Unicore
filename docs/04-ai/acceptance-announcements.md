# 公告与后端规范验收

本轮在 codex/github-ota-signing 分支实现，延续草稿 PR；不合并、不发布、不操作生产数据。

| 需求 | 影响 | 验收 |
| --- | --- | --- |
| 日志类型/详情重复 | 平台后台 | 无详情显示 —；账号、设置、模板、笔记与公告写入具体目标/变更摘要，无正文和密钥 |
| 邮件业务内容保持中文 | 平台后台/实际投递 | 默认中文与自定义草稿在中英 UI 切换时逐值保留 |
| 后端实体/分层标准 | 有数据库的业务形态 | BaseEntity、domain/usecase/adapter、分页/软删除/并发/事务鉴权规范，AST 检查；安全/账本例外有明确定义 |
| 平台公告 | web-platform 管理端/用户端 | modal CRUD、预览、批量软删除、开关、发布计划、私有备注、用户列表/详情及权限矩阵 |
| 本地排除 | standalone/desktop/cli | 无公告表、入口、请求或原生桥接；本地 appearance 保持独立 |
