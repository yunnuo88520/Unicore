# ADR-0004：M2 邮件账号流程与持久投递

状态：接受 · 日期：2026-10-26 · 作者：yunnuo / ymz@ebox.vip

M2b 承接 M2a，范围为平台 SMTP、敏感设置、邮箱验证注册、重发验证、找回密码与任务状态。注册/恢复默认关闭；其他形态不装配邮件、令牌或队列。完整角色编辑、OIDC 和备份恢复继续留在后续。

沿用 SettingDefinition、原实例 SecretStore 和现有 settings:read/write 权限。SMTP 密钥为 AES-GCM 密文，读取为空值+configured，空输入保留，clear 显式删除；错误和审计不记录密钥。SMTP 必须由真实测试发送成功才视为就绪，测试记录绑定完整配置与凭据密文版本，不保存可被离线猜测的密码快速摘要。改配置先关闭邮件账号流程，重测后再开启。

账号令牌使用 32 随机字节、SHA-256 入库、用途分离和短有效期。注册固定 user 角色、pending 状态，验证后 active。用户/令牌/加密邮件在同事务创建，重发撤销同用途旧令牌；重置原子消费并撤销全部会话和待用令牌。创建 session 时在锁内复核已验证密码哈希，避免改密与登录竞态。公开申请对未知、重复或禁用账号保持相同成功响应，叠加验证码和 IP/邮箱限流。

采用数据库任务表，服务进程单 worker，60 秒租约/10 秒发送超时/5 次上限，失败自动退避。崩溃可重领租约，投递是至少一次；不承诺 SMTP 与数据库之间的恰好一次。成功、过期、取消、终止清除载荷，元数据最多保留 7 天，后台只展示脱敏状态；已终止邮件由用户重申，而非复活旧令牌。

SMTP adapter 支持证书验证 TLS/强制 STARTTLS，禁止远程明文，loopback 明文供隔离测试或本机 relay。邮件 token 放 URL fragment，UI 捕获后移除，通过 POST 消费；API no-store，不使用 GET 自动改状态。默认系统 CA/TLS1.2+，不提供忽略证书错误的设置。

迁移 0003 只对平台增加 account_tokens/mail_jobs，保留 0001/0002 checksum。三方言需验证 M2a 升级、重试、数据保持及令牌/队列事务；测试使用临时 DB 与 loopback SMTP，不发送真实外部邮件。恢复需停 worker 并保留 DB/配置/原密钥，不能以降级旧 binary 代替一致性恢复。
