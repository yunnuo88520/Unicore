# ADR-0014：独立管理员身份与管理界面

当前入口与单机范围以 [ADR-0016](ADR-0016-separate-client-admin-surfaces.md) 为准，以下保留原决策背景。

状态：采纳，2026-10-27。身份存储与登录边界取代 ADR-0012 的同表身份分配，保留固定两角色和本地外观规则。

管理员和普通用户分别存储于 administrators/users；两域各有角色关联、session、账号令牌、六位码、企业绑定和 OIDC flow 表。管理员权限按独立仓库投影，普通用户的历史 grants 永不授权。角色目录只读，禁止通过普通用户编辑升降为管理员；管理员从独立管理入口创建。相同用户名/邮箱可在两域存在，ID 独立。

统一 API 使用 X-Unicore-Identity: user|administrator 选择身份域，默认 user，无跨域重试或凭据回退。分别使用 unicore_session/unicore_administrator_session Cookie；管理 API 同时验证所选域的有效管理员、权限、CSRF/Origin，目标账号仓库由固定端点决定。写入事务独立重新读取管理员域的操作者。共享设置、审计、权限目录和加密邮件队列属于整个实例。

普通用户入口 /login 或 /；管理员入口使用可配置 admin.path（默认 /admin）。两入口可以同时登录，各自退出。后台 HTML 是公开登录壳；普通用户 Cookie 不能在此取得管理员身份，API 仍拒绝越权。SDK 从入口选择固定身份域，修改后台路径后同步当前地址。安装完成跳转管理员入口。

OIDC 共用实例配置，但分别登记 /api/v1/auth/oidc/callback 与 /api/v1/auth/oidc/administrator-callback，两域的浏览器证明 Cookie 和持久流程独立。管理员域禁止 JIT，只接受已有绑定；普通用户 JIT 固定 user。迁移保留已有企业绑定，绝不因邮箱相同合并。六位码/兼容长链接的注册、登录和找回均限定当前域；管理员禁止自注册。密码修改校验旧密码，在安装锁内复核凭据后更新并撤销该域旧会话/挑战，不影响另一个身份域。

导航默认工作台概览，移除平台仪表盘；用户管理、系统管理各自可折叠并允许同时展开。侧栏固定视口高度，导航区独立滚动，作者区保留在底部。新增账号使用共享 Modal，支持初始聚焦、Escape、取消、返回触发点及 pending 防重。头像菜单提供改密、账号资料、退出。

系统管理包含基础设置、邮件设置、系统日志、授权与更新。基础设置保留单层 Tabs、品牌三卡片和共用外观；邮件配置/账号开关/发送测试在同页，测试收件人使用弹窗。投递记录迁到系统日志；邮件模板继续内部自动生成，不再有模板配置/预览页面。授权与更新显示通用待对接占位；实际可选集成卡片仍按编译开关裁剪，不执行检查或升级。

平台迁移 0008 创建七张管理员域表，拷贝原 super_admin 账号/密码/ID/企业绑定后从普通表删除；撤销旧凭据并取消待发邮件。框架迁移不变化。SQLite/PostgreSQL 事务执行；MySQL CREATE IF NOT EXISTS、复制防重复与删除支持部分提交后重试。回滚必须停服成套恢复 DB、私有目录/密钥和匹配程序，不能仅降级二进制。详见部署手册；真实三方言和界面证据记录于管理验收。

共享反馈采用轻量 MessageProvider/useMessage，支持 primary/success/warning/info/error、顶部居中和默认 3 秒自动移除；QueryScope 统一通知提交失败，成功消息由业务选择文案。消息跟随原生弹窗挂载以保留可访问性，字段校验和持久流程状态继续就地呈现。二级菜单向内缩进并使用配套 Lucide 图标；禁止 Emoji 图标。头像及账号菜单只出现在已登录的平台形态。
