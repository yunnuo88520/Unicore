# ADR-0015：按文件 ID 管理的私有存储

状态：采用。

在线平台新增文件服务；本地为默认，管理员测试后才能激活云位置。统一 blob.Store 负责字节，files 负责元数据、权限、生命周期，filesql 负责 SQL；组合根选择本地、MinIO/S3、OSS、COS adapter。桌面与单机品牌也使用本地 blob adapter，CLI 不装配。

文件记录固定 location_id、storage_type、file_key。更改默认位置不移动历史数据，位置目标不可原地修改；密钥可轮换、加密保存且不回传。迁移保持 file_id，成功校验后改引用，旧对象延迟清理。对外不暴露对象键，不拼接本地路径。

私有文件仅本人（含独立身份域）或管理员可申请短期下载 URL。云桶保持私有，URL 是短期 bearer，已签云链接在有效期内仍能使用；删除和迁移等待最大访问 TTL 后清理旧对象。本地链接每次校验签名、状态和有效期。下载强制 attachment，禁止应用源执行上传的 HTML/SVG。

直传凭证只写随机 staging key，确认时核验长度、类型和 ETag，再按 ETag 条件在云端复制到新正式 key，阻止原凭证覆盖完成文件。MinIO/S3 用精确 key/长度的 POST policy；OSS/COS 使用绑定 Content-Length/Content-Type 的 SDK PUT 签名（浏览器从 Blob 自动设置长度），确认阶段再次校验实际长度。未确认上传过期后删除，凭证过期前不清理 staging。所有可能的孤儿写入先登记持久清理任务；清理不扫描用户桶，只处理本实例登记的键。保留期限只作用于新上传；默认永久。

品牌是管理员显式发布的规范化 PNG，仍由公开品牌路由提供当前引用；它是私有文件规则的明确例外。旧 brand-assets 经独立 legacy-brand 位置惰性登记，不迁移或删除未登记文件。

浏览器跨域配置只合并指定站点 CORS 规则，不修改公共读策略或覆盖无关桶规则。CSP 仅允许管理员配置的位置 origin。应用清理任务不要求接管整个桶生命周期；桶 pending 前缀生命周期可作为运维后备。

平台新增 0009，三方言新增位置/文件/清理表，不改变旧迁移。回退必须停止服务，恢复匹配的 DB、数据目录、实例密钥和二进制快照；对象桶需独立版本/备份，数据库回滚不能恢复已清理对象。单实例 data-dir 锁保持，不承诺多副本共用本地目录。
