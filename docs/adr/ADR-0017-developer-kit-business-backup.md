# ADR-0017：可派生开发基座、业务样板与离线恢复

状态：接受，2026-10-28。

## 决策

创建器仅导出 Git 跟踪源码，拒绝覆盖、链接文件和仓库内目标，不复制 Git 历史、运行数据或环境文件。调用方必须指定产品名、slug、Go module、bundle ID；记录上游提交供后续三方合并。保留 MIT 与框架作者，生成派生项目 README。初始化不会运行安装器或默认初始化 Git。

增加可删除的个人笔记纵向业务样板，覆盖领域规则→usecase port→SQL→HTTP/Wails→AppClient→共享页面。scope 由入口的可信身份生成，普通用户、管理员和本地相互隔离；请求不能传 owner。附件仅引用本人同身份域的 ready file_id，文件权限仍由文件服务复核。更新和删除要求 version，审计与业务 DML 同事务。CLI 保持无数据库，不为样板强行增加持久化命令。

业务 SQL 使用独立 business_migrations，不复用 framework/platform 版本序列。现有 0001–0009 checksum 保持不变，所有有 DB 的形态在启动边界向前迁移业务 0001。保留样板数据时不能删除历史迁移；仅在派生项目首次交付前可整块移除样板与账本调用。

离线运维另建 cmd/ops，禁止进入业务 CLI。先停服并取得实例锁，再原生快照数据库、私有数据、实例密钥和全部 ready 云对象；age scrypt 流加密 tar.gz，逐成员 SHA-256 与大小校验，manifest 最后写入。密码仅通过环境输入，不在参数、源码或日志。拒绝路径穿越、链接、重复成员、超限和认证不完整的归档。工具版本记录为 tool_version，不冒充备份源应用版本。

恢复完整校验后只发布到不存在的目录，外部数据库必须明确提供 DSN 和精确确认的空专用库。PG 原生事务恢复；MySQL DDL 非事务，失败可能留下部分目标库，需弃用并换新空库。工具不自动清库，不执行迁移；正常启动才向前迁移。所有云对象恢复为本地 file_id 引用，清除云清理队列和凭据并改默认 local，避免恢复实例写回原桶。需要重新配置后再迁移回云。

## 兼容与影响

| 形态 | 变化 | 验收 |
| --- | --- | --- |
| web-platform | 独立双身份域笔记、本人附件、业务迁移；离线加密备份恢复 | SQLite/PG/MySQL、越权/CSRF/版本冲突、私有云→本地恢复、PC/375px |
| web-standalone | local scope 笔记，无平台接口；相同业务迁移 | 真实重启、分页/弹窗、备份恢复 |
| desktop | SQLite 共享笔记用例、Wails 桥接 | 原生构建与真实窗口 CRUD/重启 |
| cli | 无 DB 改动 | 实际依赖边界与构建 |

新账本是 additive；回退 binary 不删除表，但跨版本安全回退应使用变更前 binary+备份恢复到独立目录/数据库，不承诺逆向迁移。外部存储在备份期间也需停止第三方写入；本工具不能一致快照不受框架管理的外部数据。

## 发布

VERSION 仍为唯一版本源，tar 随包提供 LICENSE、运维工具、迁移等级。手动发布候选 workflow 核对版本、质量、checksum 并生成 GitHub 构建来源证明，默认不建 tag、Release 或推镜像。正式发布需人工授权、验证来源、原生签名和恢复窗口；当前没有 OTA、商业授权或自动合并上游。
