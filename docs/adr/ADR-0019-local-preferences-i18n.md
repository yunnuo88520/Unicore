# ADR-0019：共享客户端偏好与中英文界面

状态：接受。日期：2026-10-29。

## 背景

Web 用户、管理员、单机与 Wails 使用同一套界面。语言与外观属于设备偏好，不能写入实例全局设置或要求管理员身份。侧栏需要安静的版本状态入口，普通在线用户仍不能获取实例版本与更新接口。

## 决策

`packages/web-ui/src/preferences.ts` 是客户端偏好的唯一状态入口。使用版本化 `unicore.preferences.v1`，白名单校验各字段；兼容旧 `unicore.theme`，非法数据回退默认值，受限存储退回进程内存。同页通知与浏览器 storage 事件驱动 React 外部状态订阅。语言切换不重建 QueryClient、会话或业务表单；重置外观保留语言。

默认配置从 `defaultPreferences` 管理。主题构建源仍为 `assets/theme/tokens.json`：默认主色与可选预设从同一生成器推导浅深语义变量。客户端仅选择预设并应用圆角、间距和字号系数，不复制页面色值，不修改全局品牌图片、邮件或原生图标。系统主题变化实时响应。布局、侧栏、内容宽度和阅读方向同样由根 dataset/dir 与共享 CSS 处理。

`i18n.ts` 管理中文默认文案、英文 catalog、插值和日期格式；组件通过 `useLocale()` 或 `useI18n()` 订阅语言，调用 `t()`。中文原文作为 key，不在 DOM 上替换文字，不翻译笔记、文件名、实例名称、发布日志等作者数据。功能专属语言资源跟随 license/updater 编译开关裁剪；SDK、领域和后端不依赖 UI。

`ClientControls` 在工作台、安装和登录入口复用语言菜单、明暗快捷按钮与主题抽屉。`AppearanceDrawer` 使用原生 modal dialog，右侧滑入、主体独立滚动、固定页脚、Escape/遮罩关闭及回焦。外观设置页的更多设置复用同一抽屉。语言菜单支持方向键、Home/End、Enter、Escape 和 Tab。

版本气泡位于品牌名称下方；可用更新为绿色状态点，详细说明通过 hover/focus tooltip 展示。只读取本地更新概览，不在挂载时主动连接外网。普通用户 bootstrap 没有版本，组件不请求更新概览；后端权限不变化。底部只保留文档/帮助与关于入口，链接集中在 `workspaceLinks` 供派生项目替换。

## 影响与兼容

| Profile | 影响 | 验收 |
| --- | --- | --- |
| web-platform 用户 | 本地语言/外观、登录页控件；无全局管理和版本信息 | 用户权限单测、真实页面与接口回归 |
| web-platform 管理员 | 同一控件、双语管理页、版本气泡 | 真实 Go PC/375px 页面 |
| web-standalone | 本地语言/外观与版本入口 | 表单保留、跨标签、刷新与响应式验收 |
| desktop | 同源 React、原生持久化和主题抽屉 | Wails 原生构建与实际窗口 |
| cli | 无 UI，不引入新依赖 | 依赖边界与构建 |

无服务端 API、数据库结构、密钥或迁移变更；撤回此功能只需回退 UI 版本，旧主题兼容键仍可读取。受限存储的内存回退不承诺重启后保留。原生标题栏仍遵循操作系统，界面语言不改 OS 菜单。发布日志按作者提供的原文显示，离线仍可读取，不保证自动翻译外部渠道内容。
