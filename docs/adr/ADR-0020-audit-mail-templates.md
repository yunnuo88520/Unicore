# ADR-0020：可检索操作日志与可配置邮件模板

状态：采纳，2026-10-29。取代 ADR-0014 的“不展示模板管理页”及最近 50 条操作日志限制；身份隔离与形态边界保持适用。

在线管理端在系统管理中独立提供邮件模板，使用单层场景 Tabs 编辑主题与受限 HTML 正文，复用 Form、Modal、Tabs、Message、SDK、双语资源和主题 tokens。SMTP 配置及发送测试仍在邮件设置，投递记录仍在系统日志。只展示当前真实使用的服务测试、注册验证、登录验证码、密码重置和系统通知五种场景，不将未实现的通知类型做成可保存配置。

`internal/mailcontent` 负责默认内容、变量白名单、HTML 校验与转义；`mail.template.*` 由 SettingDefinition 注册并存入现有 system_settings，但通用 PATCH 禁止写入。专用 API 统一服务预览、保存、恢复和指定收件人测试。品牌页眉/Logo/版权页脚由框架保留；正文拒绝脚本、外部图片、样式、事件及任意模板执行，账号验证码必须在可见正文中出现。真实六位码、服务测试、通知与预览共用渲染器，邮件入队时快照内容。兼容长链接 API 保留旧渲染，不宣称受新配置控制。内容属于业务数据，不随 UI 语言自动翻译。

日志保留 audit_logs 的历史结构，平台迁移 0010 追加 audit_metadata 快照表，关联操作者名、身份域、目标、脱敏详情及实际连接 IP。服务端 context 注入元信息，不接收请求体伪造的 actor/IP；不信任转发头，代理后的 IP 可能是代理地址。历史缺失字段显示空缺，不从当前用户名或伪造地址补全历史。仅元数据审计，不保存密码、验证码、邮件正文、SMTP 配置值或请求体。

查询支持类型、字面关键词、时间区间、稳定排序及分页；SQL 值绑定，排序字段白名单。CSV 导出最多 10,000 条，包含截断标记、UTF-8 BOM、UTC 时间及公式注入保护。无全量采集平台或自动删除审计历史的承诺。

菜单、页面、只读和写入 API 都仅 web-platform 管理员；日志需 logs:read，模板需 settings:read/write，写请求验证 CSRF/Origin。普通用户返回 403，匿名 401；standalone、desktop、CLI 不装配。

0010 只新增表，不改已发布迁移 checksum；SQLite/PostgreSQL 事务 DDL，MySQL IF NOT EXISTS 支持 DDL 已提交但记账前失败的重试。平台 schema 为 10，本地框架仍为 1，业务账本仍为 1。跨 schema 升级须停服备份并手动部署，当前 OTA 不安装不匹配 schema 的产物。回退使用匹配的数据库、私有目录、实例密钥、对象文件快照及程序，不能承诺仅降级 binary。使用隔离三方言和真实浏览器验证，结果见对应验收记录。
