# ADR-0044：单角色个人访问令牌

状态：采纳。取代 ADR-0041 中 PAT 的 API 范围选择、有效期、管理呈现与历史清理约定；客户端 JWT、Refresh Token 和 MFA 流程继续沿用 ADR-0041。

## 功能声明

- 功能领域 / 归属层：身份治理，产品功能；用于个人脚本及外部程序的 API 调用。
- Platform：用户与管理员在个人中心管理本人令牌；超级管理员可管理所有人的令牌并代用户签发。
- Standalone 两载体 / CLI：不装配身份、令牌接口或令牌 UI；公共表单和弹窗修复适用于共享图形界面。
- 访问主体：本人已完成 MFA 的浏览器会话；全局管理要求 super_admin 及 tokens:read/write，全部写操作要求 CSRF。
- 持久化：platform@1 的凭证、刷新证明和签名密钥表。维护者明确授权在正式发版前直接重构三方言初始基线，不提供旧开发令牌迁移；不接管、重置或改写已有开发库账本。
- 契约：account/tokens、account/token-roles；admin/access-tokens 及用户选择与角色选项；移除 token-scopes。
- 界面呈现：两工作台的“个人中心 → 访问令牌”；“超级管理员 → 访问令牌管理”。无仪表盘组件。
- 依赖：统一账号、角色、平台数据库、浏览器会话与既有审计；不新增外部服务。
- 关联：RBAC、部门范围、密码/账号/角色变更、设备撤销与账号安全策略。
- 待决策事项：无；单角色、固定期限、续期作废与超级管理员管理范围由维护者明确指定。

## 决策

1. 每条 PAT 必须绑定所属用户已经拥有的恰好一个角色，签发事务复查该关系。代用户签发也只能选择目标用户的角色，不能借此分配新角色。界面不再要求用户选择 API。
2. 每次认证重新检查账号状态、角色成员关系、安全撤销锚点及期限。主体仅加载所选角色的权限点、操作和数据范围；管理写事务重新加载 actor 时沿上下文保留同一角色约束，不能扩展成账号的其他角色权限。角色的 operation 授权及资源归属继续生效。
3. 期限固定为 1、7、30、90 天或永久；永久在凭证中记为 expires_at=0。名称必填，最多 80 字；备注可留空，最多 500 字。每用户最多 50 条有效令牌，每签发操作者每小时最多创建 30 次。列表支持搜索和分页，元数据不返回原始令牌。
4. 续期不轮换秘密。有限且仍有效的令牌从原到期时间延长；已过期或永久令牌改为有限期限时从当前时间计算。选择永久则取消时间期限。安全锚点保留到账号安全变更或显式作废，因此自然过期可续期；作废和安全变更失效的令牌不能通过续期复活。
5. 锚点没有设备明细，使用独立的远期期限，不作为浏览器会话公开；凭证期限独立校验。账号禁用、密码/角色变化和“下线其他设备”仍会删除锚点；永久令牌不豁免这些规则。PAT 元数据不随客户端刷新证明的过期清理删除，以保留续期、历史与审计语义。
6. 本人只能管理自己的记录；全局管理仅限超级管理员。已禁用账号不能获得新令牌或续期，超级管理员仍可作废其保留记录。管理员代签发的秘密仅在创建响应中返回一次，不提供后续查看。
7. PAT 仅能调用可委派的业务 operation；认证、本人账号恢复/凭证管理和 superAdmin 专属接口仍不接受 PAT。即使选择 super_admin 角色也不能调用这些保留接口。管理页的隐藏不替代服务端权限、Cookie、MFA 和 CSRF 校验。
8. 表单复用契约校验及共享弹窗；提交 pending 切换不能执行关闭回焦。弹窗正文与选择菜单各有视口内滚动上限，关闭时回到打开控件，避免滚动穿透或焦点跳动。

## 验证边界

回归覆盖固定期限、永久与自然过期续期、单角色权限和读写数据范围、未分配角色、管理员代签发、本人所有权、禁用账号、作废不可恢复、无秘密列表、Cookie/CSRF/MFA、客户端刷新及原有安全撤销。浏览器覆盖两工作台、中英文、桌面及 375px 下的创建、续期、作废、焦点和滚动边界。
