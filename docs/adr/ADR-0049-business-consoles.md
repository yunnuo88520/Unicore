# ADR-0049：业务页面与可注册控制台

## 决策

Platform 的用户工作台和管理后台是内置入口，不限制派生应用增加控制台。业务流程不同但工作环境相同时，优先注册不同业务页面到内置入口。独立工作环境通过用户 Web 入口的 `defineConsoles` 注册 `/workspaces/<id>`，提供自己的外壳、导航和页面。按入口和页面权限决定呈现，多个角色可以共用一个控制台。后台不允许运营人员创建任意可执行页面或外壳。

沿用 ADR-0037 的统一会话与多角色并集。注册信息只控制前端，不新增 API realm，不切换活跃角色，不授予 API 或放宽数据范围。业务模块必须为读写 operation 完整声明服务端权限与资源约束（接入方式见开发指南"业务资源的服务端授权"）。Standalone 两载体和 CLI 不装配控制台。内置菜单配置继续用共享树与版本控制，按既有两个 surface 筛选，自定义控制台导航由业务代码维护。

控制台页面支持 `/workspaces/<id>/<page>/<rest…>` 子路由与参数，剩余段经页面 props 传入，深链接、刷新与无权限 403 由外壳统一处理；页面内的列表/详情由业务代码按 URL 渲染。每个控制台持有独立查询缓存与页面状态作用域，切换工作台即清空上一控制台的缓存；切换只改变呈现，身份、权限并集与数据范围不变。

## 兼容性

保留既有用户/管理工作台路由、账号会话与共享树。笔记管理列表使用独立的最小数据投影，提供运营所需的标题、作者、状态及更新时间，不读取正文或附件；正文预览、内容编辑、状态变更和软删除分别授权。「笔记管理」是业务管理页面，只登记在用户工作台业务区，不进入管理员工作台。新管理路径设置不能使用 `/workspaces`；已有后台路径与该保留前缀冲突时，启用控制台前需改用不冲突的路径。
