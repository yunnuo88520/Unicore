# ADR-0052：部门资源范围与受控业务产物下载

状态：采用。

## 功能声明

- 功能 ID：department-resources；领域：身份治理与业务文件存储；归属层：产品功能的框架扩展端口。
- 定位与操作对象：平台业务模块按资源当前归属部门校验明细、修改、转移及产物下载，审计创建者不作为资源归属。
- Platform：新增；使用已认证主体、模块登记的读写权限点和 operation grant；不新增超级管理员保留权限。
- Standalone：不装配部门治理；两载体保持本地业务等效。CLI：不装配身份、存储或 UI。
- 持久化：框架复用既有部门、角色和授权表，无新迁移。派生模块自己的资源、版本、文件引用与清理账本按模块迁移管理。
- 契约：新增 Go 扩展端口，无新增框架 HTTP operation；模块的下载接口先声明完整 OpenAPI 策略再生成。
- 呈现：无新增菜单、页面或仪表盘组件；模块决定其业务呈现，沿用现有权限与双语规则。
- 条件与关联：Platform 统一账号、多角色、PAT 单角色；复用私有 blob.Store 和实例 Secrets。无新的待决策事项。

## 归属与授权

`ScopeFilter.DepartmentIDs` 与 `ContainsDepartment` 表达部门拥有的资源，`UserIDs/Contains` 保留用户拥有语义。`DataScope` 同时返回部门与用户集合；只需要部门时使用 `DepartmentScope`，避免为部门资产枚举成员。dept 为当前部门，dept_and_below 加后代，custom 为显式部门（包括空部门）。self、未知值、无相关权限均不赋予部门。空部门 ID 不表示归属，连 all 也不把它变成部门授权；实例拥有资源须单独建模。

仅授予目标权限点的角色参与并集。all 只取消该权限的行范围，不能授予 operation 或其他权限；PAT 的绑定角色在 resolver 和事务重读中保持。数据库错误必须返回失败。创建者调岗或删除不改变资源的 department_id。

模块查询在分页、计数、明细、导出和文件选择时复用相同的当前部门条件，并排除已删除资源。写事务先持有 `LockInstallation`，读取并锁定实际资源，再调用 `AuthorizeDepartmentMutation` 交集校验写权限与所有浏览先决权限。转移用 `AuthorizeDepartmentTransfer` 对持久化源部门和目标部门逐一校验全部权限范围；同一事务执行版本 CAS、变更与审计，失败全部回滚。旧 `AuthorizeScopedMutation` 的 ownerID 语义保留。

## 业务产物端口

`files.ControlledStore` 接受模块私有命名空间的 `blob.Store` 与 `ResourceAuthorizer`。它不把部门产物注册成个人文件，不修改 CreatorID，不伪造 Admin，也不扩大 CreatorIDs。既有通用个人文件的同 realm 范围读取、拥有者捷径与删除规则保持。

模块持久化 `ResourceFile` 对应的 file_id、不可变对象键、名称、类型、长度和资源关系，负责写入、引用保护及清理账本；字节只经 blob.Store，不拼路径或存临时 URL。`WithResourceFiles` 从当前请求取得可信主体（含凭证/角色约束），在资源读事务或等价锁内重新检查操作授权、权限特定部门范围、当前归属、删除状态及每个文件绑定；直到回调返回才释放保护，写入/转移须使用同一串行化边界。

`Sign` 只返回绑定主体、资源版本和完整选中文件清单的短期 opaque token。模块的已认证下载 endpoint 在每次请求调用 `Open`；后者再次走相同授权、验证版本及清单，然后直接打开私有对象字节。云端也经应用流式转发，绝不发放云端 bearer URL。多个文件重新流式生成 ZIP，名称隔离且条目与 count 来自同一精确选择；任意条目失去权限则整包拒绝，不静默扩大或删减已签清单。

资源转移、删除或替换产物必须更新 Revision；权限撤销则由每次当前主体复核生效。旧 token 在读取对象前失效。模块可保留历史批次外壳，但其明细、可见文件计数和重新签发选择仍按当前资源范围计算。禁止将此端口返回的 ZIP 静态缓存后绕过 `Open` 提供；旧个人文件/云直链不具备这一撤权保证，迁入部门业务时必须使用独立私有对象及新引用。授权发生于下载开始，已发出的字节无法撤回；请求取消时必须关闭返回 reader。

## 兼容与验证边界

不改变文件 metadata schema 或个人文件状态机。端口不宣称提供具体设备/订单业务；模块仍须实现资源仓储与参考完整性。跨方言 scope/事务回归使用真实隔离数据库，下载回归使用合成模块及真实私有字节，禁止将这些夹具描述为生产设备验证。
