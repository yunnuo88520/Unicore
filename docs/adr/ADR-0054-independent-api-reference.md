# ADR-0054：独立开发者文档与菜单显示语义

状态：已接受（2026-11-28，维护者明确要求独立 Web 入口、公开只读契约与旧实例定向清理）。

API 描述是开发者资料，不属于工作台菜单或角色可分配页面。沿用默认关闭的 `api_docs` 开关；启用后 `/api-docs` 与 `/openapi.json` 公开只读，`/docs/api` 兼容跳转。页面独立装配，不加载工作台会话；业务操作继续按原契约和服务端权限执行。桌面与 CLI 不装配 HTTP 文档入口，裁决 D2 为 Web 载体开发工具差异，不新增桌面产品页面。

旧菜单是规范化表中的 JSON payload，已有 EnsureNavigation 启动协调机制。沿用同一安装锁与事务清理 `type=page, route_id=api-docs` 的旧框架绑定，匹配路由而非可修改的名称/ID，不清理业务链接或其他未注册模块。保留自定义后代及隐藏/停用意图，保留无关角色权限与动作/API 授权；只删退役节点自身菜单授权并递增版本。不发生结构变化，无新增 Catalog 版本，不改历史 SQL。失败回滚并拒绝继续启动；恢复使用升级前匹配快照。

菜单“允许显示”是配置意图。当前账号显示状态消费真实侧栏渲染结果，解释同时存在的功能、形态、工作台、祖先与授权条件；已保存配置与草稿分开，不以提示改写服务端授权。

功能声明：开发者工具/运行载体实现；Platform 与 Standalone Web 条件支持公开契约，desktop/CLI 不适用；菜单管理仅 Platform、沿用 menus:write 和既有角色分配保留集；复用现有导航/授权表，无新权限点、设置键、业务 operation 或仪表盘。详见 [开发者文档](../product/api-reference.md)。
