# MCP 客户端接入

Platform 可通过 MCP Server 向外部客户端开放业务工具。客户端以用户身份发现和调用工具，沿用角色、API operation 和数据范围授权。框架不提供模型调用服务或内置 AI 助手。

MCP 只在 `web-platform` 装配，默认关闭。Standalone 和 CLI 不提供 `/mcp` 或 AI 管理页面。

## 启用服务与工具

由超级管理员完成以下配置：

1. 打开“AI 管理 → 接入配置”，核对接入地址，启用 MCP 服务，并选择允许个人令牌或 OAuth 接入。
2. 根据部署容量设置请求体、响应体、超时、并发和频率限制，保存配置。
3. 打开“工具目录”，查看代码注册的工具、关联 operation、版本和风险，明确开放所需工具。
4. 给使用者的角色授予 `mcp:access` 及工具关联的业务权限和 operation。仅分配菜单不授予调用权。

新工具默认不开放。工具定义或指纹变化后，需要超级管理员重新审查；后台不能改绑工具权限或降低风险声明。管理员修改同一配置发生版本冲突时，重新读取并确认后保存。

生产接入使用 HTTPS，本机开发可用回环 HTTP。浏览器客户端需使用可信的 Origin，额外来源在接入配置中逐条精确登记。

## 使用个人访问令牌

1. 管理员在接入配置中允许个人令牌。
2. 用户在“个人中心 → 访问令牌”创建令牌，绑定一个已有角色。该角色需要 `mcp:access` 和目标工具的业务授权。
3. 在支持 Streamable HTTP 的客户端中填写页面显示的 MCP 地址，并使用 `Authorization: Bearer <PAT>`。

秘密只在创建时显示一次，存入客户端的安全凭据配置。不要把令牌粘贴到聊天正文、公开配置或仓库。平台 Cookie 和普通登录 JWT 不能代替 MCP 凭证。

PAT 只继承所选角色，不合并其他角色。令牌作废、角色撤销或账号安全状态变化后，后续请求立即重新检查授权。个人令牌操作见 [API 认证](api-authentication.md)。

## 使用 OAuth 授权

管理员启用 OAuth，并在“AI 管理 → OAuth 接入”注册客户端，填写精确的回调地址。公开客户端使用授权码 + PKCE；机密客户端的秘密只在创建或轮换时展示一次。

用户从客户端发起连接后，会进入平台授权页：登录账号，选择自己已经拥有的一个角色，确认授权范围。一次授权绑定一个账号、客户端和角色。

访问令牌有效期为 15 分钟，刷新令牌最长 30 天并在每次刷新时轮换。客户端应替换旧凭证；重复使用旧刷新令牌会撤销整个令牌族。用户可在个人中心“已授权应用”撤销授权，管理员也可停用客户端或撤销其授权。

动态客户端注册需单独启用，入口为 `/oauth/mcp/register`，仅支持公开 PKCE 客户端。默认关闭，兼容范围与普通预注册客户端相同。

## 当前可用范围

| 能力 | 行为 |
| --- | --- |
| 工具发现与调用 | 支持 Streamable HTTP，实际协议版本见接入配置页 |
| 笔记只读示例 | `notes.search`、`notes.get`，按角色数据范围和归属返回数据 |
| 笔记裁剪 | `FEATURE_NOTES=false` 时不注册笔记工具，MCP 底座保留 |
| 写入工具 | 受写入开关、业务授权及 OAuth `mcp.write` 范围共同约束 |
| 需要本人确认的工具 | 当前拒绝执行；笔记更新示例属于此类，开启写入开关也不能绕过 |
| 破坏性工具 | 当前关闭 |
| Resources / Prompts | 尚未提供 |

MCP 没有独立的 `FEATURE_MCP` 构建开关，使用运行期启停和逐工具开放策略。业务模块可以通过注册表增加工具；工具权限应绑定既有可委派 operation，不能以超级管理员身份跳过用户授权。

## 排查连接与调用

| 现象 | 检查 |
| --- | --- |
| `/mcp` 返回 404 | 实例是否为 Platform |
| `/mcp` 返回 503 | MCP 服务是否启用 |
| 无法认证 | 凭证类型、到期与作废状态，是否启用了对应接入方式 |
| 工具不在目录中 | 代码是否注册、是否被裁剪、开放策略与指纹、角色和 operation 授权是否满足 |
| 写工具不可用 | 写开关、OAuth scope、风险及确认门禁；确认门禁当前始终拒绝 |
| 请求被限制 | 接入配置中的超时、频率、并发和体积预算 |

“AI 管理 → 调用记录”提供脱敏调用元数据，不保存原始参数、结果或凭据。服务关闭或权限收紧会影响后续发现与调用。

源码入口为 `internal/adapter/mcp/handler.go`、`internal/mcp/registry.go` 和 `internal/adapter/mcp/notes.go`。
