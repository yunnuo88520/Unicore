# 本地文件与对象存储

在线平台由管理员在存储设置中配置；默认本地，云存储测试成功后才激活。支持本地、MinIO/S3 兼容、阿里云 OSS 与腾讯云 COS 适配器；实际云权限、网络、CORS 和大文件续传须针对自己的环境验收，不能因适配器存在就认为所有云账号可用。单机/桌面不装配平台存储管理端。

无独立文件管理页面；文件服务与统一上传组件供业务接入。管理员可配置单文件大小等上传限制，全局默认存储启用后，新上传统一使用该方式。业务以 file_id 引用元数据，经服务端授权后生成短期签名 URL；不能在业务中拼接本地 /uploads 路径或将私有文件永久公开。上传可能走服务端转存，也可能由后端发放有时效/限定对象键的直传签名，让浏览器直接上传。

配置 Endpoint、Bucket、区域、Access Key/Secret 时使用私有实例配置，公网页面/API 响应不返回秘密。只授予目标前缀必要的读写、列举/完成/中止分片、复制与 CORS 权限，不把凭据嵌入前端。浏览器直传需桶允许实际站点 origin、PUT/分片方法及所需头；不要无条件公开整桶。

大文件支持分片、断点续传和上传会话；客户端重新选择同一文件后续传，凭证过期要重新获取。设置有效期/清理策略，清理确认后才删除内容；已有文件的存储位置由元数据标识，切换新位置不意味着旧对象自动迁移。

Nginx/反代体积与超时、后端限制、桶策略须一致。上传后验证授权下载、过期签名、普通用户越权、删除/恢复与续传。无权限时先修正策略，不关闭签名和授权。

数据库只保存元数据，不等于文件备份。跨存储迁移、桶独立备份与灾难恢复见 [备份](backup.md)；本地目录必须随 [部署](deployment.md) 独立持久化。

对象存储页按当前全局方式进入对应表单，通过横向按钮查看各方式的一份配置；只切换表单不会启用该方式。页面不提供位置名称或新增位置。云配置保存、测试连接、配置本站跨域后，可在表单底部“设为全局默认”，顶部统一显示使用中的方式。已保存的目标地址、Bucket、Region 与前缀只读，密钥留空保留原值；旧版位置继续服务历史文件，不自动删除。独立“上传规则”页签支持逐条增删多个上传相对路径（首项默认，上传时可选择），以及允许的文件扩展名（每行一个，可带点，支持 tar.gz，不区分大小写，留空不限制）。大小、链接有效期和保留天数直接展示，分片上传与自动清理收纳在折叠项中。限制在后端同时校验单请求与分片上传；历史文件与已发起会话保持原目标。详细参数与恢复见 [配置说明](configuration.md)。

## 从笔记体验上传

Platform 与 Standalone 的“我的笔记 → 新建/编辑 → 附件”可直接上传文件，完成后加入草稿，保存笔记后关联。也可选择本人已有 ready 文件，最多五个。删除笔记或移除引用不会删除原文件；上传后取消笔记仍可在下次选择该文件。Platform 下载按笔记读取范围签发短链接，Standalone Web 使用本地签名下载，桌面使用系统保存对话框。

上传按钮使用笔记的 notes:create/update 权限及 notes* helper API 授权，读取使用 notes:access，不需要 files:* 管理权限。头像上传属于本人账号能力，限 PNG/JPEG/GIF、2 MiB，服务端校验实际图片。角色例子见 [应用开发](development.md#常用角色与权限排查)。弹窗可暂停和放弃；在笔记弹窗按文件名选择“继续上传”，重选原文件即可续传；派生业务的恢复入口传 resume FileEntry，不保存签名 URL 或 File 对象到 localStorage。

Standalone Web/桌面共用本地文件服务，不提供对象存储配置或通用文件管理页；数据目录中的文件、未完成分片、数据库及签名密钥须整体备份。接入与权限说明见 [应用开发](development.md#常用角色与权限排查)。
