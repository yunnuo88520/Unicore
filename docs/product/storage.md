# 文件与对象存储

框架文件服务供头像、业务附件及上传组件使用，业务通过 `file_id` 引用文件。Platform 管理员可以配置本地或对象存储；Standalone Web 和桌面使用本地文件，不提供平台存储管理页。Platform 超级管理员可在“文件管理”统一查看和治理已登记文件，普通用户和 Standalone 不提供全局文件管理。

## 选择存储方式

| 方式 | 配置 |
| --- | --- |
| 本地 | 默认方式，文件保存在实例私有数据目录，需独立持久化 |
| MinIO / S3 兼容 | Endpoint、Bucket、Region、访问凭据及对象前缀 |
| 阿里云 OSS | 对应区域的 Endpoint、Bucket、访问凭据及前缀 |
| 腾讯云 COS | Endpoint、Bucket、Region、访问凭据及前缀 |

已有开发验证覆盖本地、MinIO 和 OSS。COS 及其他 S3 服务需要在自己的环境验证权限、跨域和分片上传，具体范围见 [支持与兼容性](https://unicore.ebox.vip/support)。

## 配置平台存储

1. 在管理工作台打开对象存储设置，选择目标方式。切换表单只是在编辑配置，不会更换当前存储。
2. 填写目标地址、桶、区域、前缀和访问凭据，保存后测试连接。
3. 浏览器直传时，按实际站点 Origin 配置桶的 CORS，允许所需 PUT、分片方法和请求头。
4. 测试成功后，点击“设为全局默认”。后续新上传使用该方式，旧文件继续使用元数据记录的位置。
5. 上传一个测试文件，确认下载、链接过期后的重新获取、暂停和续传都正常。

已保存的地址、Bucket、Region 与前缀只读，密钥留空表示保留原值。凭据加密保存，不回显到页面或 API。桶只授予目标前缀所需的读写、分片、复制等权限，不公开整桶，也不把凭据写入前端。

切换默认位置不会迁移或删除历史文件，旧位置仍需保持可访问。

## 查看文件与迁移存储

管理工作台的“文件管理”位于运行监控与 AI 管理之间，仅超级管理员可用。左侧按存储位置和上传目录浏览，右侧分页展示业务附件、头像与品牌资源；可搜索文件名或文件 ID，查看上传者姓名/账号、状态、大小与上传时间，并获取授权下载链接。目录来自实例元数据，不扫描 Bucket 内的其他对象。

全局同时只有一个生效位置，新上传使用该位置。只支持本地与云存储双向迁移，不支持云厂商或云位置之间直接互迁。配置并测试目标后，在文件管理选择文件或迁移当前筛选下可转换的就绪文件；选择云目标时只纳入本地文件，选择本地目标时纳入云端文件。页面显示进度与失败项；迁移保留文件 ID 和目录，业务无需修改引用。复制与摘要核验成功才切换位置，旧对象延迟清理；确认迁移完成前保持源位置和凭据可用。可选择全部迁移成功后将目标设为全局默认；失败时保留当前默认。切换默认位置只影响新上传。

批量操作在当前页面运行，关闭页面会中断后续迁移；已完成文件保持迁移结果，可按源位置筛选后继续。迁移期间新上传的文件不自动加入当前批次。正在被品牌设置、头像或笔记引用的文件不能删除，需先从业务处解除引用。到期清理也会保留这些文件；保留期依然限制下载，解除引用后按原到期时间清理。

## 设置上传规则

“上传规则”页签可设置多个相对上传路径，首项作为默认路径，上传时可选择。扩展名每行一个，可带点，支持 `tar.gz` 等复合扩展名，不区分大小写；留空则不限制。

还可调整单文件大小、签名链接有效期、文件保留天数、分片和自动清理策略。限制由后端同时校验；已发起的会话保留原存储目标。反向代理、CDN 和桶的体积及超时限制也应与应用策略匹配。

## 在笔记 demo 中体验附件

Platform 与 Standalone 的笔记弹窗可上传附件或选择本人已有文件，最多五个。上传完成后先加入草稿，保存笔记才会建立关联。删除笔记或移除引用保留原文件，供后续再次选择。

上传支持暂停和放弃。刷新或重启后，在笔记弹窗选择继续上传，并重新选择原文件即可续传。Web 下载使用有时效的授权链接，桌面使用系统保存对话框。

笔记上传使用 `notes:create/update` 及对应 helper API，读取使用 `notes:access` 和资源归属校验，不需要 `files:*` 管理权限。头像属于本人账号能力，仅接受 PNG/JPEG/GIF，最大 2 MiB，服务端检查实际图片内容。角色配置见 [笔记权限示例](https://unicore.ebox.vip/03-runbooks/business-example#角色与权限示例)。

## 业务接入与备份

开发者复用共享上传组件和 AppClient 的业务文件入口；数据库保存 `file_id`，不拼磁盘路径，也不持久保存临时签名 URL。接口和恢复语义见 [配置参数](configuration.md) 与 [笔记源码导读](https://unicore.ebox.vip/03-runbooks/business-example)。

备份时需同时保存数据库、文件、未完成分片和签名密钥；仅备份文件元数据无法恢复内容。见 [备份恢复](backup.md) 与 [Web 部署](deployment.md)。
