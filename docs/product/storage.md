# 本地文件与对象存储

在线平台由管理员在存储设置中配置；默认本地，云存储测试成功后才激活。支持本地、MinIO/S3 兼容、阿里云 OSS 与腾讯云 COS 适配器；实际云权限、网络、CORS 和大文件续传须针对自己的环境验收，不能因适配器存在就认为所有云账号可用。单机/桌面不装配平台存储管理端。

管理员可配置单文件大小等上传限制。业务以 file_id 引用元数据，经服务端授权后生成短期签名 URL；不能在业务中拼接本地 /uploads 路径或将私有文件永久公开。上传可能走服务端转存，也可能由后端发放有时效/限定对象键的直传签名，让浏览器直接上传。

配置 Endpoint、Bucket、区域、Access Key/Secret 时使用私有实例配置，公网页面/API 响应不返回秘密。只授予目标前缀必要的读写、列举/完成/中止分片、复制与 CORS 权限，不把凭据嵌入前端。浏览器直传需桶允许实际站点 origin、PUT/分片方法及所需头；不要无条件公开整桶。

大文件支持分片、断点续传和上传会话；客户端重新选择同一文件后续传，凭证过期要重新获取。设置有效期/清理策略，清理确认后才删除内容；已有文件的存储位置由元数据标识，切换新位置不意味着旧对象自动迁移。

Nginx/反代体积与超时、后端限制、桶策略须一致。上传后验证授权下载、过期签名、普通用户越权、删除/恢复与续传。无权限时先修正策略，不关闭签名和授权。

数据库只保存元数据，不等于文件备份。跨存储迁移、桶独立备份与灾难恢复见 [备份](backup.md)；本地目录必须随 [部署](deployment.md) 独立持久化。
