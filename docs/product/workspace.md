# 框架能力与示例应用

本页说明框架内置界面和可选笔记 demo 的使用方式。开发自己的产品时，可按 [功能裁剪](features.md) 关闭笔记并替换为业务模块。Platform 提供用户与管理工作台；Standalone 的 Web 和桌面载体提供相同的本地业务，无需平台账号。

## 创建与编辑笔记

在侧栏打开“我的笔记”，点击“新建”，填写标题和正文后保存。编辑已有笔记时，若其他页面或设备已经更新该记录，保存会提示版本冲突；重新读取最新内容后再编辑。

Platform 根据角色和数据范围限制列表、编辑及删除操作。页面能打开但缺少按钮时，请让管理员检查角色授权。Standalone 使用本地数据，不提供多用户角色管理。

## 添加附件

在新建或编辑笔记的弹窗中上传文件，或选择本人已上传的文件，每条笔记最多关联五个附件。上传完成后，保存笔记才会建立关联。

上传可以暂停或放弃。继续上传时选择原文件；刷新页面或重启后，也可以从笔记弹窗恢复未完成的上传。移除附件引用或删除笔记会保留原文件，供后续再次选择。

Web 下载使用有时效的授权链接，过期后重新点击下载即可。桌面下载会打开系统保存对话框。上传大小、格式和存储方式见 [文件存储](storage.md)。

## 账号、通知与外观

| 任务 | 入口 | 适用范围 |
| --- | --- | --- |
| 修改资料、密码、两步验证或登录设备 | 头像菜单 → 个人中心 | Platform |
| 查看站内信 | 顶栏铃铛 | 所有图形界面 |
| 查看平台公告 | 铃铛公告标签 | Platform 普通用户 |
| 切换语言、明暗与主题 | 顶栏语言和外观按钮 | 所有图形界面 |

详细操作见 [个人中心](https://unicore.ebox.vip/03-runbooks/personal-center)、[公告与站内信](https://unicore.ebox.vip/03-runbooks/announcements)、[语言与外观](https://unicore.ebox.vip/03-runbooks/client-preferences) 和 [管理工具](https://unicore.ebox.vip/03-runbooks/admin-tools)。

## 查看运行状态

Platform 的超级管理员可打开“运行监控”，查看概览、服务、资源和运行事件，并管理告警规则。Standalone 在本地运行监控页提供对应信息，内置告警写入运行事件，不发送外部通知。

资源数值会标明采集视角；容器中的系统资源信息取决于运行环境。长期指标存储与 Prometheus 接入见 [配置说明](https://unicore.ebox.vip/product/configuration#_7-日志、健康、数据与密钥)。

## 保存与迁移数据

Web 实例的数据目录应独立持久化。桌面数据保存在系统应用数据目录的 `Unicore/desktop` 下，可用 `APP_DATA_DIR` 指定位置。迁移或卸载前，按 [备份恢复](backup.md) 保存数据库、私有目录、文件和密钥。
