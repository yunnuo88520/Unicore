# Unicore 文档

一份 Go Core，一套 React UI，连接在线平台、单机 Web、原生桌面与 CLI。Unicore 自带多形态装配、OpenAPI 单一契约、统一设计源、平台身份/设置/文件存储，以及可运行的业务样板和 AI 开发 Skills。

当前为开发预览，采用 MIT。真实授权与 OTA、正式系统签名/公证仍待接入；先阅读 [当前能力与限制](../00-product/PRD.md) 和 [最新验收](../04-ai/acceptance-developer-kit.md)。
