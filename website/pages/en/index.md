## Current development documentation

Unicore is a 0.x development preview. This site follows documentation on `main` and can describe changes that have not been released. For an installed release, consult the matching Git tag and release notes.

The homepage and [getting started](getting-started.md) are available in English. Detailed guides are primarily in Chinese; links to those guides are marked **中文**. See [support boundaries (中文)](../../../docs/support.md) before choosing a deployment target.
